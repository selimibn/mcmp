El Espíritu del Curso

Cerrando la Brecha entre Física e Ingeniería

Este curso va mucho más allá de simplemente "escribir código". Su objetivo es adoptar la mentalidad de un Ingeniero de Software de Investigación (RSE):

  • Reproducibilidad: Garantizar que tus resultados científicos puedan ser verificados de forma independiente.
  • Sustentabilidad: Diseñar código modular que sobreviva más allá de una sola publicación.
  • Rendimiento: Extraer el máximo potencial del hardware moderno.

¿Qué Hace a un Buen Físico Programador?

El Enfoque "Típico"

  • Scripts monolíticos desordenados de miles de líneas.
  • Control de versiones manual (codigo_v1_final_v2.py).
  • Valores y rutas de archivos harcodeadas localmente.
  • Código que solo funciona una vez en tu propia máquina.

El Enfoque del Curso (MCMP)

  • Diseño Modular: Lógica de la física acoplada limpiamente.
  • Flujo Git Profesional: Ramas limpias organizadas por características.
  • Portabilidad Absoluta: Entornos virtuales reproducibles (Conda).
  • Optimización Real: Uso de profiling matemático antes de compilar.

Módulo I: Research Software Engineering

Semanas 1–2: Cimientos de Desarrollo

Transición crítica del desarrollo artesanal al desarrollo de software científico modular y colaborativo.

  • Control de Versiones: Ramificación en Git y gestión en GitHub.
  • Verificación: Pruebas unitarias para asegurar estabilidad matemática.
  • CI/CD: Automatización de pruebas de software en la nube.

Referencia: Wilson, G. et al. (2014). Best Practices for Scientific Computing. PLOS Biology.

Módulo II: High-Performance Foundations

Semanas 3–6: Velocidad y Escala

  • Profiling: Medición precisa de cuellos de botella con cProfile.
  • Vectorización: Uso correcto del layout de memoria en NumPy.
  • JIT Compilation: Compilación a lenguaje máquina nativo vía Numba.
  • Paralelismo distribuido: Message Passing Interface (MPI) con mpi4py.

Referencia: Gorelick, M., & Ozsvald, I. (2020). High Performance Python (2nd Ed.).

Git: El Único Canal de Entrega

¿Por qué Git?

No es solo una herramienta de entrega, es el pilar de la reproducibilidad científica moderna. Permite auditar exactamente qué ecuaciones cambiaron, cuándo y por qué.

Mecánica de Evaluación del Curso

  • Cada tarea se entregará mediante un **Push** a un repositorio privado de GitHub asignado.
  • Las entregas fuera de tiempo se miden por la marca de tiempo exacta del *commit* en el servidor.
  • Se evaluará la limpieza del historial, el uso de ramas descriptivas y la presencia de entornos reproducibles en el repositorio.

El Panorama Académico Mexicano

Desafíos y Ventaja Competitiva

  • Exigencias del SNI: Mantener tasas de publicación científica competitivas requiere herramientas propias veloces, evitando cuellos de botella experimentales.
  • Restricciones de Hardware: Muchas universidades carecen de supercomputadoras masivas. Escribir código optimizado estira al máximo el hardware local disponible.
  • Redes Internacionales: La integración en colaboraciones de frontera (Lattice QCD, HEP) exige programar bajo estándares industriales compartidos.

Diferenciación Profesional

En las convocatorias de oposición nacionales, un perfil físico con dominio de arquitectura computacional y HPC destaca de inmediato sobre los enfoques tradicionales.

La "Póliza de Seguro" Profesional

Los egresados de física poseen habilidades analíticas de élite; el código estructurado es el puente para monetizarlas en cualquier industria.

Data Science & FinTech

La familiaridad con inferencia bayesiana robusta abre posiciones de ingeniería de datos complejas en hubs financieros nacionales.

Administración HPC

Los sysadmins que gestionan clusters científicos entendiendo los modelos subyacentes de la física son extremadamente cotizados.

Políticas Públicas

El modelado matemático avanzado se utiliza cada vez más para simular optimización de recursos y dinámicas complejas en gobiernos locales.
