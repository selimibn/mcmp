Los Módulos del Curso

Estructura detallada y referencias fundamentales de los cuatro bloques de aprendizaje.

Módulo I: Research Software Engineering (RSE)

Cimientos de Desarrollo Profesional

Transición crítica del desarrollo artesanal al desarrollo de software científico modular y colaborativo.

  • Control de versiones avanzado: Flujos de trabajo ramificados en Git y gestión en GitHub.
  • Robustez: Pruebas unitarias y de regresión automatizadas con PyTest.
  • Automatización: Integración continua (CI/CD) mediante GitHub Actions.
  • Mantenibilidad: Documentación ágil y entornos reproducibles (Conda).

Referencia Obligatoria:
Wilson, G. et al. (2014). Best Practices for Scientific Computing. PLOS Biology, 12(1), e1001745.

Módulo II: High-Performance Foundations

Cómputo Científico de Alto Rendimiento

Identificación de limitaciones en hardware y optimización matemática orientada a procesadores modernos.

  • Profiling: Diagnóstico preciso de CPU y memoria usando cProfile.
  • Vectorización: Uso avanzado de layouts de memoria e internals de NumPy.
  • Aceleración JIT: Compilación directa a código máquina con Numba.
  • Paralelismo: Computación en clusters de memoria distribuida con MPI.

Referencia Obligatoria:
Gorelick, M., & Ozsvald, I. (2020). High Performance Python: Practical Performant Programming for Humans (2nd Ed.). O'Reilly Media.

Módulo III: Inferencia Bayesiana

Conexión entre Teoría Física y Datos

Cuantificación de incertidumbre y exploración de espacios de parámetros complejos mediante técnicas probabilísticas.

  • Fundamentos: Teorema de Bayes aplicado a problemas físicos reales.
  • Muestreadores MCMC: Implementación de algoritmos afines al invariante (emcee, PyMC).
  • Diagnósticos: Autocorrelación y criterios de convergencia robustos.
  • Emulación: Procesos Gaussianos para acelerar simulaciones lentas.

Referencias Clave:
Sivia, D. S., & Skilling, J. (2006). Data Analysis: A Bayesian Tutorial. Oxford University Press.
Foreman-Mackey, D. et al. (2013). emcee: The MCMC Hammer. PASP, 125, 306.

Módulo IV: Aprendizaje Automático Científico

Inteligencia Artificial con Rigor Físico

Aplicación de redes neuronales y aprendizaje estadístico preservando la interpretabilidad de las leyes de la física.

  • Clasificadores: Separación de señal y fondo mediante BDTs y Random Forests.
  • Modelos Sustitutos (Surrogates): Redes Neuronales para emular sistemas de ecuaciones diferenciales (EDOs/EDPs).
  • Active Learning: Diseño óptimo de experimentos y simulaciones.

Referencia Obligatoria:
Acquaviva, V. (2023). Machine Learning for Physics and Astronomy. Princeton University Press.

Git: El Estándar de Entrega

¿Por qué Git?

Es el estándar industrial absoluto para rastrear cambios, colaborar sin colisiones y certificar que la ciencia realizada es reproducible e íntegra.

Entrega de Tareas

Todas las evaluaciones se entregarán vía repositorios en GitHub. Se evaluará el historial de commits, el uso correcto de ramas, el manejo de dependencias y el README.

Mercado Laboral en México

El ingreso y permanencia en el Sistema Nacional de Investigadores exige una productividad científica alta. Diseñar tu propio software eficiente y escalable te permite publicar análisis complejos sin depender de hardware inalcanzable.
