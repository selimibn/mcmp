# Módulo IV: Aprendizaje Automático para el Modelado Científico

El aprendizaje automático (machine learning) se ha convertido en una herramienta importante para acelerar simulaciones, identificar patrones en grandes conjuntos de datos y construir modelos sustitutos. El énfasis aquí es la utilidad científica en lugar de los sistemas de IA a gran escala.

## Temas

### Aprendizaje Supervisado

* Entrenamiento, validación y prueba
* Compromiso sesgo-varianza (bias-variance tradeoff)
* Sobreajuste (overfitting)

### Clasificación en Física

* Clasificación de señal frente a fondo
* Árboles de decisión
* Bosques aleatorios (random forests)

### Reducción de Dimensionalidad

* Análisis de Componentes Principales (PCA)
* Extracción de características
* Visualización de datos de alta dimensión

### Modelos Sustitutos de Redes Neuronales

* Redes neuronales prealimentadas (feed-forward)
* Aproximación de funciones
* Emulación de simulaciones
* Aplicaciones científicas

### Aprendizaje Activo y Optimización

* Optimización Bayesiana
* Uso de Procesos Gaussianos para guiar ejecuciones de simulación
* Funciones de adquisición

### Aprendizaje Automático Científico (SciML)

* Interpretabilidad
* Estimación de incertidumbre
* Limitaciones de los métodos de ML
