# Módulo I: Ingeniería de Software para la Investigación

Este módulo introduce la mentalidad y las herramientas necesarias para construir software científico robusto.

## Tópicos 

### Diseño de Software Científico

* Scripts frente a software
* Modularidad
* Organización del código
* Documentación
* Reproducibilidad

### Control de Versiones con Git

* Repositorios locales
* Estrategias de ramificación (branching)
* Fusión (merging)
* Flujos de trabajo colaborativos
* GitHub/GitLab

### Pruebas de Software Científico

* Pruebas unitarias
* Pruebas de regresión
* Verificación numérica
* Conceptos de integración continua

### Empaquetado y Entornos

* Conceptos básicos de empaquetado en Python
* Entornos virtuales
* Gestión de dependencias
* Entornos computacionales reproducibles
